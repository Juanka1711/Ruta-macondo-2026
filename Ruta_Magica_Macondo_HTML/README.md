# Ruta Mágica de Macondo 2026

Sitio web estático creado a partir del documento Word «Ruta mágica de macondo 2026».

## Uso
1. Descomprime el ZIP.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. No requiere PHP, XAMPP, MySQL ni instalación.
4. Tailwind CSS y las fuentes web se cargan mediante CDN cuando hay conexión; los estilos propios y el contenido funcionan sin internet.

## Archivos
- `index.html`: estructura principal.
- `styles.css`: diseño adaptable.
- `app.js`: buscador, filtros, lectura de capítulos, galería y navegación.
- `datos.js`: contenido precargado para que funcione abriendo el HTML directamente.
- `contenido.json`: versión editable del contenido.
- `assets/`: imágenes originales extraídas del documento.

Para actualizar contenido, modifica `datos.js`; `contenido.json` es una copia de consulta y no se carga automáticamente.
